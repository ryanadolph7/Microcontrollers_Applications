This repository contains all of my code that was written for EELE 465 Microcontroller Applications at Montana State University with the help of my partner Andrew Kernen. 
Ignore some of the folder names, Andrew was my only partner. Most code was written in C, with the exception of project_0 which was written in assembly. 

The projects are designed to run on a MSP430FR2355 development board, a MSP430FR2153, and a MSP430FR2310. The directory layout was made by my professor and given to us to use as our layout for projects. 
I used Code Composer Studio to write and upload all of my coded the the MSP430, as well as used an Analog Discovery Oscilloscope to test functionality and accuracy of projects.
